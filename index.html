Link quality = aircraft packets received vs sent, last 5 s. RSSI: closer to 0 is stronger (about −120 dBm is the radio's limit). Noise: more negative is quieter. Fade margin = RSSI above noise, the best single measure: 20 dB or more is solid. dBm values are approximate (SiK raw / 1.9 − 127).

Packet rate, telemetry ratio and switch mode are set on the handset (ELRS Lua) and follow it automatically.

      

      

        
Output power

        
Power of the telemetry this ground station sends to the handset. RC from the handset uses the handset's own power (ELRS Lua → TX Power). Applying re-syncs the handset link for about a second.

        

          
          
        

        
The SX1281 has no amplifier on this board: +13 dBm (20 mW) is its maximum.

      

      

        
Binding phrase

        
Must match the handset's phrase exactly (capitals and symbols count). Saving reboots the board, which pauses RC for a few seconds.

        

          
          
        

        
Binding ID for this phrase: –

        

          
        

      

      

        
Bind with the handset

        
Puts the receiver into bind mode (the handset link drops). Then press Bind in the handset's ELRS Lua script; the new binding is saved.

        

      

    

  


  
  

    

      

        
RC rate to aircraft

        
RC_CHANNELS_OVERRIDE frames per second over the RFD900. Higher is more responsive but uses more of the 57600-baud link (about 0.9% per Hz).

        

          
          
        

      

      

        
Ground position to aircraft

        
Sends GLOBAL_POSITION_INT at 2 Hz as system 255 when the GPS has a fix. For ArduPilot Follow mode set FOLL_ENABLE=1 and FOLL_SYSID=255.

        

          
          
        

      

      

        
Board

        

          
          
        

        
A reboot drops the handset link and stops RC to the aircraft for about 3 seconds. Blocked while the aircraft is armed.

        AT console
        

          
          
        

        

        
Each command runs in its own short session: the ground station enters command mode, runs it, shows the reply and returns to normal operation.

      

    


    

      

        Command reference
        
From RFDesign's SiK 3.x manual. Every AT command has an RT twin that runs on the linked aircraft radio. Run sends a read-only command (after a confirm); Insert puts a setting command in the console for you to edit.
